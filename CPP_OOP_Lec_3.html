مبادئ البرمجة الشيئية وتصميم الكلاسات

شرح وافٍ لفلسفة الـ OOP، الكلاس كقالب تصميمي، صياغة الكائنات (Objects)، تغليف البيانات (Encapsulation)، وتصميم واجهات التحكم

فلسفة البرمجة الشيئية (Object-Oriented Programming Paradigm)

بص يا هندسة، البرمجة مش مجرد كتابة سطور كود وخلاص. البرمجة ليها مدارس فكرية بنسميها **Programming Paradigms** (النماذج البرمجية)، وهي الطريقة اللي بنفكر بيها وإحنا بنصمم السيستم بتاعنا.

الفرق الجوهري بين البرمجة الإجرائية والبرمجة الشيئية:

البرمجة الإجرائية (Procedural)

بتعتمد على أسلوب **Top-Down** (من فوق لتحت). البرنامج عبارة عن قائمة من الأوامر والدوال والتعليمات اللي بتتنفذ خطوة خطوة ورا بعضها لتعديل بيانات منفصلة عنها.

البرمجة الشيئية (OOP)

البرنامج بيتقسم لكائنات ذكية ومستقلة (**Objects**)، كل كائن بيجمع جواه بياناته الخاصة ودوال التحكم فيها، وبيتفاعل مع الكائنات التانية كأنهم عايشين في بيئة واحدة.

الـ Object بالبلدي

الـ **Object** هو كائن حقيقي (سواء ملموس زي الطالب أو غير ملموس زي الخصم أو فاتورة السوبرماركت)، بيتكون دايماً من شقين رئيسيين:
1. **Data (Attributes):** الخصائص والبيانات زي الاسم والسعر.
2. **Behaviors (Operations/Methods):** الأفعال والتصرفات اللي يقدر يعملها زي تعديل السعر أو حساب الراتب.

جدول مصطلحات المحاضرة (Terminology Glossary):

المصطلح العلمي (English) المعنى البرمجي (Arabic) الشرح المبسط بالبلدي
Programming Paradigm نموذج برمجي طريقة التفكير في هيكلة وبناء السوفت وير.

ما هو الكلاس (Class) ولماذا نحتاجه؟

تخيل يا هندسة لو إحنا شغالين في نظام جامعة وعايزين نعمل بيانات لـ 3 طلاب. في البرمجة العادية، الطالب الأول هيكون ليه اسم ورقم وتلفون، والتاني نفس البيانات، والتالت نفس البيانات. لو قررنا فجأة نضيف "الإيميل" لكل الطلاب، هنضطر نعدل في كود كل طالب يدوياً! دي فوضى وبتستهلك وقت.

الكلاس هو الكتالوج البرمجي (Blueprint)

الـ **Class** هو الكتالوج الأساسي أو الرسم الهندسي اللي بنحدد فيه إيه الخصائص والدوال اللي هتكون عند أي طالب. ومن الكتالوج ده نقدر نخلق (Instantiate) مئات الكائنات (Objects) الفعلية في الذاكرة بقيم مختلفة!

العلاقة بين الكلاس والكائن (Class vs Object):

  • Blueprint Analogy: الـ Class عامل زي **الرسم الهندسي لبيت** (مفهوم نظري مش موجود في الميموري كأشياء حقيقية). بينما الـ Object هو **البيت الفعلي** اللي تم بناؤه على أرض الواقع (محجوز في الميموري ولي مساحة!).
  • Code Specifier: الكلاس بيمثل **الكود المكتوب** في الملف، بينما الكائن هو **Instance** (حالة شغالة في الذاكرة) لما البرنامج يشتغل ويبدأ يحجز الأماكن دي بالقيم الفعلية.

تغليف وحماية البيانات (Data Hiding & Access Specifiers)

بص يا هندسة، في البرمجة الشيئية عندنا مبدأ ذهبي اسمه **Data Hiding** (إخفاء البيانات). المبدأ ده بيقول: **"مينفعش الكود اللي برة الكلاس يلمس أو يعدل البيانات الداخلية بتاعة الكائن مباشرة"**.

محددات الوصول في الـ C++ (Access Specifiers):

الـ C++ بتوفر كلمات مفتاحية بتنظم حدود الوصول لعناصر ودوال الكلاس:

private: العناصر الخاصة (الحماية القصوى)

كل العناصر أو الفانكشنز المكتوبة هنا **لا يمكن** قراءتها أو تعديلها من خارج الكلاس نهائياً! الدوال اللي جوة نفس الكلاس بس هي اللي تقدر تلمسها.

public: العناصر العامة (الواجهة المفتوحة)

كل العناصر والفانكشنز المكتوبة هنا مسموح لأي كود خارجي في الـ main() أو أي مكان تاني يستدعيها ويعدلها مباشرة.

الـ Getters والـ Setters بالبلدي

عشان نعدل البيانات الـ private بأمان، بنعمل بوابات أمان public بنسميها:
1. **Setters (Mutators):** دوال بتسمح لنا نكتب البيانات بس بعد ما نتأكد إنها صحيحة (Validation). مثلاً: دالة لتغيير الطول تتأكد إن القيمة مش سالبة!
2. **Getters (Accessors):** دوال بتسمح لنا نقرأ القيمة المخفية فقط بدون ما نعدل فيها.

التطبيق العملي: كلاس المستطيل المتكامل (Rectangle Class)

دلوقتي يا هندسة، هنطبق كلاس المستطيل اللي اتذكر في السلايدات بالتفصيل، بس مع حماية كاملة للبيانات باستخدام الـ Encapsulation وفحص المدخلات عشان نمنع حد يكتب أطوال سالبة!

rectangle_class.cpp
#include <iostream>
using namespace std;

// تعريف الكلاس
class Rectangle {
private:
    float length; // طول المستطيل (مخفي وآمن)
    float width;  // عرض المستطيل (مخفي وآمن)

public:
    // دالة لتعديل الطول مع حماية أمان (Validation)
    void setLength(float len) {
        if (len >= 0) {
            length = len;
        } else {
            cout << "Warning: Length cannot be negative! Set to 0." << endl;
            length = 0;
        }
    }

    // دالة لتعديل العرض مع حماية أمان (Validation)
    void setWidth(float w) {
        if (w >= 0) {
            width = w;
        } else {
            cout << "Warning: Width cannot be negative! Set to 0." << endl;
            width = 0;
        }
    }

    // دوال القراءة (Getters)
    float getLength() {
        return length;
    }

    float getWidth() {
        return width;
    }

    // دالة حساب المساحة
    float getArea() {
        return length * width;
    }
};

int main() {
    // إنشاء كائن (Object) من الكلاس Rectangle
    Rectangle rect1;

    // محاولة إدخال قيم باستخدام الـ Setters
    rect1.setLength(5.5);
    rect1.setWidth(4.0);

    // طباعة البيانات باستخدام الـ Getters ودوال العمليات
    cout << "--- Rectangle Specifications ---" << endl;
    cout << "Length: " << rect1.getLength() << endl;
    cout << "Width: " << rect1.getWidth() << endl;
    cout << "Area: " << rect1.getArea() << endl;

    // اختبار حماية الأمان (محاولة إدخال قيمة سالبة)
    cout << "\nTesting invalid input security:" << endl;
    rect1.setWidth(-3.5); 
    cout << "Current Width: " << rect1.getWidth() << " | Current Area: " << rect1.getArea() << endl;

    return 0;
}

شرح تفصيلي لطريقة عمل الكود:

  • class Rectangle { ... }; هنا بنقول للـ Compiler: احفظ قالب تصميمي جديد باسم **`Rectangle`** يحتوي على متغيرات خاصة ودوال عامة.
  • private: float length; المتغيرات دي بقت **private**؛ يعني لو حاولت في الـ main تكتب rect1.length = 5; الكود هيطلع **Compile Error** فوراً!
  • void setLength(float len) { if (len >= 0) ... } بوابة الأمان؛ دالة **Setter** بتفحص القيمة المدخلة عشان تضمن دقة البيانات البرمجية والهندسية وتمنع الكسور أو الأبعاد السالبة.
  • Rectangle rect1; هنا قمنا بعمل **Instantiation** وحجز مساحة كائن حقيقي في الذاكرة يُدعى `rect1`.

Practical Challenges:

Challenge 1: Student Class and Protecting GPA
Write a class named Student that contains a private variable for GPA. Design the setGPA function so that it only allows updates if the value is between 0.0 and 4.0; otherwise, print a warning and automatically set the value to 0.0. Design a getter function getGPA to view the result.

تحليل الحل البرمجي:

بص يا هندسة، هنا عملنا فحص أمان مركب باستخدام الـ **Logical AND `&&`** لحصر الدرجة في المدى الأكاديمي الصحيح، وده بيضمن دقة بيانات الطالب:

student_gpa_solution.cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    float GPA;

public:
    void setName(string sname) {
        name = sname;
    }

    void setGPA(float val) {
        // حماية البيانات: الـ GPA الأكاديمي محصور بين 0.0 و 4.0
        if (val >= 0.0 && val <= 4.0) {
            GPA = val;
        } else {
            cout << "Warning: Invalid GPA (" << val << ")! Resetting to 0.0." << endl;
            GPA = 0.0;
        }
    }

    string getName() {
        return name;
    }

    float getGPA() {
        return GPA;
    }
};

int main() {
    Student s1;
    s1.setName("Zain Ahmed");
    
    // محاولة إدخال GPA خاطئ
    s1.setGPA(5.3); 
    cout << s1.getName() << " GPA: " << s1.getGPA() << endl;

    // إدخال GPA صحيح
    s1.setGPA(3.85);
    cout << s1.getName() << " New GPA: " << s1.getGPA() << endl;

    return 0;
}
Challenge 2: Complete Design of a Circle Geometric Class
Design a geometric class Circle that contains radius radius as a private member, setter/getter functions, and functions to compute the area and circumference of the circle using a constant PI value of 3.14159.

تحليل الحل البرمجي:

بص يا هندسة، الدائرة بتعتمد على نصف القطر عشان نحسب كل حاجة. هنا عملنا فحص للتأكد من أن نصف القطر أكبر من أو يساوي الصفر، وطبقنا القواعد الرياضية للمساحة والمحيط بنجاح:

circle_class_solution.cpp
#include <iostream>
using namespace std;

class Circle {
private:
    float radius;
    const float PI = 3.14159; // ثابت رياضي

public:
    void setRadius(float r) {
        if (r >= 0) {
            radius = r;
        } else {
            cout << "Warning: Radius cannot be negative! Set to 0." << endl;
            radius = 0;
        }
    }

    float getRadius() {
        return radius;
    }

    // دالة حساب المساحة (PI * r^2)
    float getArea() {
        return PI * radius * radius;
    }

    // دالة حساب المحيط (2 * PI * r)
    float getPerimeter() {
        return 2 * PI * radius;
    }
};

int main() {
    Circle c;
    c.setRadius(7.0);

    cout << "--- Circle Specifications ---" << endl;
    cout << "Radius: " << c.getRadius() << " cm" << endl;
    cout << "Area: " << c.getArea() << " sq cm" << endl;
    cout << "Perimeter: " << c.getPerimeter() << " cm" << endl;

    return 0;
}
