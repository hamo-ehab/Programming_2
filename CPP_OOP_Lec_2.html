مفهوم الـ Struct وتطبيقاته البرمجية

شرح شامل للتراكيب المخصصة (Structures)، مقارنة المتغيرات، الدوال الهيكلية، المصفوفات، والـ Nested Structs

ما هو الـ Struct ولماذا نحتاجه؟

بص يا هندسة، إحنا عارفين إن الـ **Array** تقدر تخزن كذا قيمة بس لازم كلهم يكونوا من **نفس النوع** (كلهم أرقام صحيحة، أو كلهم نصوص، إلخ). طب لو عايزين نعمل سجل كامل لطالب أو موظف فيه بيانات مختلفة؟ يعني الموظف ليه كود (integer)، واسم أول وثاني (string)، وراتب أساسي وبونص (float). هنا بييجي دور الـ **Struct**!

الـ Struct بالبلدي

الـ **Struct** عبارة عن "علبة مخصصة" بتعملها بنفسك (Custom Data Type)، بتجمع جواها متغيرات تانية بأنواع مختلفة حسب رغبتك. المتغيرات اللي جوة دي بنسميها **Members** أو عناصر.

الصيغة العامة لتعريف الـ Struct (Syntax):

struct_definition.cpp
struct struct_name
{
    Datatype member1;
    Datatype member2;
    // ...
    Datatype memberN;
}; // أوعى تنسى الفصلة المنقوطة هنا!
المطب الشهير: الفصلة المنقوطة (Semicolon `;`)!

لو نسيت الفصلة المنقوطة `;` بعد القوس المقفول بتاع الـ `struct` الكومبيلر هيطلعلك أخطاء غريبة جداً ومش هيفهم الكود. دي بتيجي كتير جداً في امتحانات الـ C++!

مثال عملي: كلاس سجل الموظف (Employee Struct)

تطبيقاً على كلام الدكتور عمرو، هنا بننشئ كلاس هيكلي للموظف:

employee_struct.cpp
#include <iostream>
#include <string>
using namespace std;

// تعريف الـ Struct
struct Employee {
    int emp_no;
    string fname;
    string lname;
    float salary;
    float bonus;
    float net_salary;
};

int main() {
    // إنشاء متغيرات من نوع Struct
    Employee emp1, emp2;
    
    // إعطاء قيم للموظف الأول باستخدام معامل النقطة "."
    emp1.emp_no = 12;
    emp1.fname = "Ahmed";
    emp1.lname = "Ali";
    emp1.salary = 3000.0;
    emp1.bonus = 500.0;
    
    // حساب الراتب الصافي
    emp1.net_salary = emp1.salary + emp1.bonus;

    // طباعة البيانات على الشاشة
    cout << "Employee No: " << emp1.emp_no << endl;
    cout << "Full Name: " << emp1.fname << " " << emp1.lname << endl;
    cout << "Net Salary: " << emp1.net_salary << " EGP" << endl;

    return 0;
}

شرح تفصيلي للأسطر وكيف تعمل:

  • struct Employee { ... }; هنا إحنا بنقول للـ Compiler: احفظ عندك نوع بيانات جديد اسمه **`Employee`**، دا لسه مش بيحجز مكان في الذاكرة لحد ما نخلق منه متغير.
  • Employee emp1; هنا حجزنا في الميموري مكان كامل باسم **`emp1`**، جواه خانات منفصلة لكل الـ members المحسوبين.
  • emp1.emp_no = 12; استخدمنا الـ **Dot operator `.`** (معامل الوصول). كأنك بتقول: "يا رامات ادخلي جوة العلبة `emp1` ودوري على الدرج المسمى `emp2.emp_no` واكتبي فيه 12".

عمليات التعيين والمقارنة في الـ Struct

بص يا هندسة، في قواعد صارمة لازم تعرفها بخصوص العمليات اللي مسموح تعملها على الـ Struct ككتلة واحدة (Aggregate Operations):

1. عملية التعيين أو النسخ (=): مسموحة! ✅

لو عندك اتنين متغيرات من **نفس نوع الـ Struct**، تقدر تنسخ واحد في التاني بـ `=` مباشرة. الكومبيلر هيعمل نسخ عنصر عنصر (Member-wise Copy) تلقائياً:

assignment.cpp
Employee emp1, emp2;
emp1.emp_no = 12;
emp1.fname = "Ahmed";

// عملية نسخ كاملة ومباشرة!
emp2 = emp1; 

cout << emp2.fname; // هيطبع "Ahmed" بنجاح وسهولة!

2. العمليات الحسابية والعلاقية (==, !=, <, >): ممنوعة! ❌

متقدرش تقارن متغيرين struct ببعض مباشرة كدا: if (emp1 == emp2). الكومبيلر مش هيفهم وهيطلعلك **Compile Error** علطول!

ليه الكومبيلر بيرفض المقارنة المباشرة؟

لأن الكومبيلر مش بيبقى عارف يقارن بناءً على إيه؟ هل يقارن برقم الموظف؟ ولا بالمرتب؟ ولا بالاسم؟ عشان كدا إنت لازم تقارن عنصر بعنصر (Member-wise Comparison) بنفسك.

comparison_demo.cpp
// الطريقة الخاطئة (هتسبب compile error):
// if (emp1 == emp2) { ... }

// الطريقة الصحيحة (مقارنة الأعضاء بالتفصيل):
if (emp1.emp_no == emp2.emp_no && emp1.fname == emp2.fname && emp1.salary == emp2.salary) {
    cout << "Employees are identical" << endl;
}

تعامل الـ Struct مع الـ Functions

الـ Struct مرن جداً في التعامل مع الفانكشنز، عندك طريقتين عشان تبعته كمعامل:

  • Pass by Value: بيبعت نسخة من الـ Struct بالكامل (بيستهلك مساحة لو الحجم كبير).
  • Pass by Reference: بيبعت المتغير الأصلي باستخدام الـ & (أسرع بكتير وبيرفر الميموري).

وكمان الفانكشن تقدر ترجع متغير من نوع Struct كامل كـ **Return Type**!

نصيحة هندسية بخصوص جمع كائنات الـ Struct

بص يا هندسة، لما تيجي تعمل دالة بتجمع بين مسافتين (مثلاً d1 و d2)، ركز جداً في كتابة الأكواد. لازم تجمع عنصر من الكائن الأول مع نفس العنصر من الكائن الثاني، يعني:
result.inches = d1.inches + d2.inches;.
لو اتلخبطت وكتبت d2.inches + d2.inches الكود هيشتغل بس النتيجة هتطلع غلط منطقياً! وإحنا هنا هنكتب الكود الصح والمثالي مع معالجة ذكية للكسور.

كود جمع المسافات (المثال الصحيح والمعالج هندسياً):

distance_sum.cpp
#include <iostream>
using namespace std;

struct distance_type {
    int feet;
    float inches;
};

// إعلان الدالة (Function Declaration)
// الفانكشن دي بتاخد اتنين struct وبترجع struct تالت
distance_type Add_distances(distance_type d1, distance_type d2);

int main() {
    distance_type dist1 = {5, 8.5};  // 5 قدم و 8.5 بوصة
    distance_type dist2 = {3, 6.2};  // 3 قدم و 6.2 بوصة
    
    distance_type sum = Add_distances(dist1, dist2);
    
    cout << "Total Distance: " << sum.feet << " feet, " << sum.inches << " inches" << endl;
    return 0;
}

// تعريف الدالة (Function Definition)
distance_type Add_distances(distance_type d1, distance_type d2) {
    distance_type result;
    result.feet = d1.feet + d2.feet;
    result.inches = d1.inches + d2.inches; // تصحيح الخطأ المطبعي!
    
    // لمسة هندسية: لو البوصات زادت عن 12 (لأن 12 بوصة = 1 قدم)
    if (result.inches >= 12.0) {
        result.feet += 1;
        result.inches -= 12.0;
    }
    
    return result;
}

تحليل عمل الفانكشن:

  • distance_type Add_distances(...) هنا نوع الإرجاع هو الـ struct المسمى distance_type، ودا بيبين مرونة الـ C++ في إرجاع كتل معقدة من البيانات.
  • if (result.inches >= 12.0) دي معالجة فيزيائية منطقية؛ بنحول كل 12 بوصة لـ 1 قدم إضافي ونخصمهم من البوصات، لضمان دقة النتائج الهندسية.

المصفوفات والـ Structs المتداخلة (Nested)

هنا بنبدأ ندخل في الهياكل المعقدة اللي بتشبه الأنظمة الحقيقية في سوق العمل. عندنا 3 حالات رئيسية:

أ. مصفوفة بداخل Struct (Arrays inside Struct)

الحالة دي لما يكون الـ Struct نفسه بيحتوي على مصفوفة كعنصر جواه (زي الطالب اللي جواه مصفوفة درجاته في 3 مواد):

array_in_struct.cpp
struct Student {
    int student_no;
    string sname;
    float GPA;
    float marks[3]; // مصفوفة درجات لثلاث مواد
};

int main() {
    Student s1;
    s1.student_no = 120;
    s1.sname = "Ahmed Ibrahim";
    s1.GPA = 3.56;
    
    // إسناد القيم للمصفوفة الداخلية
    s1.marks[0] = 80; // المادة الأولى
    s1.marks[1] = 70; // المادة الثانية
    s1.marks[2] = 90; // المادة الثالثة
}

ب. مصفوفة من الـ Structs (Arrays of Structs)

الحالة دي لما نحب نخزن كذا موظف أو كذا طالب؛ بنعمل مصفوفة كاملة نوعها هو الـ Struct بتاعنا:

array_of_structs.cpp
struct Employee {
    int emp_no;
    string fname;
    float salary;
};

int main() {
    Employee company[5]; // مصفوفة تتسع لـ 5 موظفين
    
    // إدخال بيانات الموظف الأول (Index 0)
    company[0].emp_no = 101;
    company[0].fname = "Zain";
    company[0].salary = 8000;
    
    // إدخال بيانات الموظف الثاني (Index 1)
    company[1].emp_no = 102;
    company[1].fname = "Omar";
    company[1].salary = 9500;
    
    // لوب لطباعة مرتبات كل الموظفين
    for (int i = 0; i < 2; i++) {
        cout << company[i].fname << " earns: " << company[i].salary << " EGP" << endl;
    }
}

ج. تركيب Struct بداخل Struct (Nested Structs)

دي بنستخدمها لما يكون كائن بيحتوي على كائن تفصيلي جواه (زي الموظف اللي جواه عنوانه المفصل):

nested_structs.cpp
#include <iostream>
#include <string>
using namespace std;

// الـ Struct الداخلي للعنوان
struct Address {
    string city;
    string street;
    int building_no;
};

// الـ Struct الخارجي للموظف
struct Employee {
    int emp_no;
    string fname;
    Address addr; // تداخل: Address جوة Employee!
};

int main() {
    Employee emp;
    emp.emp_no = 55;
    emp.fname = "Ali";
    
    // الوصول للعناصر المتداخلة بـ 2 نقطة "."
    emp.addr.city = "Cairo";
    emp.addr.street = "El-Tahrir St";
    emp.addr.building_no = 14;
    
    cout << emp.fname << " lives in " << emp.addr.city << ", " << emp.addr.street << endl;
    return 0;
}

كيف يتم الوصول للـ Address؟

  • emp.addr.city = "Cairo"; أول نقطة `.` بتدخلك جوة الموظف لتجيب الـ Address، وتاني نقطة `.` بتدخلك جوة الـ Address لتصل للمدينة! تداخل مرن جداً ومنظم.

Practical Challenges:

Challenge 1: Writing a custom comparison function for a Struct
Since the compiler rejects using == to compare two struct instances directly, write a function named isEqual that takes two variables of type struct Point and returns a bool indicating whether their coordinates (X and Y) are completely identical.

الحل البرمجي الصحيح:

بص يا هندسة، هنا بنبعت الـ `Point` بالـ **const reference** عشان نضمن السرعة وعدم استهلاك الميموري بدون داعي، ونقارن الأعضاء عنصر عنصر:

struct_comparison_solution.cpp
#include <iostream>
using namespace std;

struct Point {
    int x;
    int y;
};

// دالة المقارنة الذكية والآمنة
bool isEqual(const Point& p1, const Point& p2) {
    return (p1.x == p2.x && p1.y == p2.y);
}

int main() {
    Point a = {10, 20};
    Point b = {10, 20};
    Point c = {5, 20};

    if (isEqual(a, b)) {
        cout << "Point A and Point B are Equal." << endl;
    } else {
        cout << "Point A and Point B are NOT Equal." << endl;
    }

    return 0;
}
Challenge 2: Managing an array of nested structures and finding the best
Write a complete program that defines a student structure Student containing student ID, name, GPA, and an array of marks for 3 subjects. Initialize an array of 3 students, read their details, and write a search algorithm to find the student with the **highest GPA** and print their name, ID, and full marks table.

الحل البرمجي المتكامل:

بص يا هندسة، هنا طبقنا مصفوفة كاملة من الـ Structs وجواها مصفوفة تانية للدرجات وعملنا خوارزمية بحث (Search Algorithm) بسيطة لحساب الطالب المتفوق:

student_system.cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    int student_no;
    string sname;
    float GPA;
    float marks[3];
};

int main() {
    // مصفوفة من 3 طلاب
    Student classroom[3] = {
        {101, "Zain Ahmed", 3.85, {85, 90, 95}},
        {102, "Omar Gamal", 3.92, {92, 94, 98}},
        {103, "Youssef Eid", 3.71, {80, 85, 88}}
    };

    // خوارزمية إيجاد صاحب أعلى GPA
    int bestStudentIndex = 0;
    float maxGPA = classroom[0].GPA;

    for (int i = 1; i < 3; i++) {
        if (classroom[i].GPA > maxGPA) {
            maxGPA = classroom[i].GPA;
            bestStudentIndex = i;
        }
    }

    // طباعة بيانات الطالب المتفوق
    Student best = classroom[bestStudentIndex];
    cout << "==========================================" << endl;
    cout << "🏆 TOP STUDENT FOUND 🏆" << endl;
    cout << "Name: " << best.sname << endl;
    cout << "ID: " << best.student_no << endl;
    cout << "GPA: " << best.GPA << endl;
    cout << "Marks in 3 Subjects: ";
    for (int j = 0; j < 3; j++) {
        cout << best.marks[j] << " ";
    }
    cout << endl << "==========================================" << endl;

    return 0;
}
